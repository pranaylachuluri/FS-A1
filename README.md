# Java DSA & SQL Practice

Solutions to 100 coding practice problems: 72 data-structures and algorithms problems in Java and 28 SQL queries.

Each file holds the problem statement and sample test cases in a comment block at the top, followed by the solution.

## Contents

| Files | What's inside |
| --- | --- |
| `d<day>p<n>.txt` | Java problems, by training day and problem number (for example `d16p2.txt` is day 16, problem 2) |
| `BFSlevelOder.txt` | Level-order (BFS) traversal of a binary tree |
| `q1.txt` – `q28.txt` | SQL queries on the `classicmodels` sample database (customers, orders, order details, employees, products) |

## Topics covered

**Java:** arrays and sorting, the k-th smallest element without sorting, next-greater-element with stacks, queues and deques, HashMap counting, linked lists, binary trees (BFS and DFS), grid and matrix traversal, recursion and permutations, and substring problems.

**SQL:** `SELECT` with `WHERE`, `LIKE`, `BETWEEN` and `IN`, `ORDER BY` and `LIMIT`, aggregates (`COUNT`, `SUM`, `AVG`) with `GROUP BY` and `HAVING`, `DISTINCT`, and `JOIN`s across orders and order details.

## Run a Java solution

The files are saved as `.txt`. To run one, copy the code into a `.java` file named after its main class, then:

```bash
javac Solution.java && java Solution
```
